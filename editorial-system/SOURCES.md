# Approved Sources — cut to 5 high-signal

Rule: if a source publishes more than 3 times a week, it's a
firehose, not a signal source. Kept deliberately short.

## Tier 1 — Primary data (always cite these for numbers)
1. **IEA** — iea.org/news — policy + data, publishes ~2×/week
2. **Ember Climate** — ember-energy.org/insights — grid/power data,
   sharpest on emerging markets coal-to-renewables
3. **IRENA** — irena.org/publications — MEA-specific renewable data
   and finance flows

## Tier 2 — Signal / interpretation
4. **Reuters Energy** — reuters.com/business/energy — deal flow,
   policy announcements, faster than IEA
5. **Bloomberg Opinion (David Fickling + Javier Blas)** —
   bloomberg.com/opinion — interpretive signal on what a data
   point *means* — use for angle calibration, not citation

## Tier 3 — Morocco/MEA specific (check monthly, not weekly)
- **ONEE press** — onee.org.ma/actualites
- **MASEN** — masen.ma/en/actualites
- **AfDB projects** — afdb.org/en/news-and-events
- **OCP Group** — ocpgroup.ma (industrial load signal)

## Explicitly excluded (and why)
- **a16z** — investor POV, not primary data
- **Le Grand Continent** — geopolitics, too slow/broad for weekly
- **Bloomberg NEF free blog** — shallow vs their paid research;
  not worth the signal-to-noise
- **Exponential View / Ben Evans** — great for macro framing,
  not MEA-specific enough for weekly use (read personally, don't
  feed to Scout)

## When to add a source
Only if it passes the Scout signal test twice in one month via a
manual tip from Reda. Default is to keep the list narrow.
