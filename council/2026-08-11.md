### Ruling

SHIP:    OBJ-security-engineer-2 — the highest-ranked ready S item on the
         board this sitting. Rung 3 ("the audience cannot make a decision
         it should be able to make"): a regulator evaluating the map
         against the data-protection bar they'd apply to their own
         agency's tools could not previously see the third-party data flow
         without opening devtools themselves. No rung-1/2 candidate
         pre-empted the docket (state check above). OBJ-map-debugger-1
         (dead mailto) was carried forward from 2026-08-04 as
         next-ranked, but the Chair held it this sitting rather than
         ruling it SHIP: fixing it requires choosing a real, monitored
         email address to expose publicly as the correction-report target,
         and no address has been designated anywhere in this repo for
         that purpose. Picking one unilaterally — the only candidate in
         reach being the repo owner's personal address — would put a
         personal inbox in a public, permanently-indexed corrections link
         once merged and deployed, which is a decision with a real privacy
         consequence for a specific person, not a reversible S-sized
         technical change. The Chair is not positioned to make that call
         without the owner's confirmation, so OBJ-map-debugger-1 stays
         Docketed, next-ranked, pending that input (flagged to the user
         outside this PR). OBJ-security-engineer-2 required no such
         external decision — implemented, gated, and shipped clean.
         Execution surfaced one real gap mid-flight: security-engineer's
         first accuracy pass (a self-review the objective itself calls
         for) found the disclosure omitted `demotiles.maplibre.org`, the
         MapLibre demo glyph server every labeled map layer fetches fonts
         from on load. Sent back to frontend-engineer, fixed, and
         security-engineer re-verified PASS on the corrected diff before
         this shipped — the gate did its job.

REPORT:  OBJ-coord-validator-2, OBJ-platform-engineer-1 — both actually
         executed this sitting (not just re-affirmed on paper, unlike
         2026-08-04's handling of the same two items). coord-validator
