# Council minutes

One file per day: `YYYY-MM-DD.md`. Each sitting appends a
`## Sitting — HH:MM (Europe/Paris)` section, per COUNCIL.md §7.

Sittings run every 5 hours. The SHIP budget is **1 per rolling 24 h across
all sittings** — the Chair reads the day's file before approving one, and a
sitting that finds nothing worth shipping records that and stops.

Minutes are the memory. A sitting that does not read the previous minutes
will re-propose objectives that were already vetoed or already shipped.
