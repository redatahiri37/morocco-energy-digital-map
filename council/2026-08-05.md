   `national-hv.geojson` carries no `source_url` at all;
   `transmission-lines.geojson`'s `source_url` is a generic World Bank data
   catalog homepage (HTTP 403 on fetch), not a per-feature record, so it

   **Verdict: structurally sound, provenance-unverified.** Notable finding

   independently-attributed files are suspiciously close (225kV 416 vs
   418; 400kV 110 vs 113; 150kV 10 vs 10) — suggests shared upstream
   (likely OSM) lineage despite differing `source` fields. This should be
   disclosed in-product if/when the layers are ever wired in, not silently
   dropped. **This clears the data-quality blocker on OBJ-map-debugger-2**
   (now noted UNBLOCKED on the Board — still L, still needs splitting

2. **OBJ-platform-engineer-1** — rescoped from a vague M into a concrete,
   genuinely S-sized first slice. Confirmed: no `.github/workflows/`
   exists; all `docs/data/**/*.geojson` files are plain well-formed
   `FeatureCollection` JSON (stock `python3 -m json.tool`-class validation
   suffices, no schema library needed); the load path in `docs/app.js`
   (`loadAllData()`, lines 237–258) resolves paths as
   `dataPath + layers[].file` from `docs/countries.config.js`. Proposed
   slice (a) — ship-sized: a single-job GitHub Actions workflow
   (`.github/workflows/validate.yml`) that JSON/GeoJSON-validates every
   `docs/data/**/*.geojson` file using only stock `ubuntu-latest`
   `python3` (no npm, no bundler, no build step — clears the structural
   veto by construction). Full YAML:

   ```yaml
   name: Validate data
   on:
     push:
       branches: [main]
     pull_request:
   jobs:
     geojson-json-valid:
       runs-on: ubuntu-latest
       steps:
         - uses: actions/checkout@v4
         - name: Validate JSON well-formedness and GeoJSON shape
           run: |
             set -e
             shopt -s globstar nullglob
             files=(docs/data/**/*.geojson)
             if [ ${#files[@]} -eq 0 ]; then
               echo "No .geojson files found under docs/data/ — nothing to validate."
               exit 0
             fi
             fail=0
             for f in "${files[@]}"; do
               python3 -c "
   import json, sys
   f = sys.argv[1]
   try:
       d = json.load(open(f))
   except Exception as e:
       print(f'FAIL {f}: not valid JSON — {e}'); sys.exit(1)
   if d.get('type') != 'FeatureCollection' or 'features' not in d or not isinstance(d['features'], list):
       print(f'FAIL {f}: not a FeatureCollection with a features array'); sys.exit(1)
   print(f'ok   {f}  ({len(d[\"features\"])} features)')
   " "$f" || fail=1
             done
             exit $fail
   ```
